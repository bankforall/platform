## 1. พ.ร.บ.การเล่นแชร์ พ.ศ. 2534

| ประเด็น | ความเข้าใจปัจจุบัน (ต้องยืนยัน) | ใน v2 ทำแล้ว |
| --- | --- | --- |
| นิติบุคคลเป็นนายวงแชร์ไม่ได้ | บริษัทต้องเป็นแค่ผู้ให้บริการซอฟต์แวร์ และนายวงต้องเป็นบุคคลธรรมดา | host = บุคคลที่ผ่าน KYC ส่วนบริษัทไม่ได้เป็นสมาชิกหรือผู้รับเงิน |
| เพดานของนายวงที่เป็นบุคคล | จำนวนวงพร้อมกัน, จำนวนสมาชิก, มูลค่าทุนรวม (ใช้ 3 วง / 30 คน / 300,000 บาท เป็นค่าเริ่มต้น) | บังคับใน `CircleFactory` (แก้ค่าได้) และใน `createCircleSchema` |
| นายวงห้ามรับประโยชน์ตอบแทนอื่น | การที่ host ได้ "มือแรก" ถือเป็นประโยชน์ต้องห้ามหรือไม่? | `hostTakesFirst` เปิด/ปิดได้ |
| platform เก็บค่าบริการได้หรือไม่ | ค่าบริการรายเดือนต่อผู้ใช้ ต่างจากการหักจากวงหรือไม่? | ยังไม่มี revenue model |
| การนับวงที่ host หลายคนร่วมกัน / host ใช้หลายบัญชี | KYC 1 คน = 1 บัญชี | ผูก attestation กับ KYC |

## 2. ธนาคารแห่งประเทศไทย

- [ ] ระบบที่ **ไม่ถือเงิน** (โอนตรงระหว่างสมาชิก) ยังต้องขอใบอนุญาต e-money / payment หรือไม่
- [ ] การประมูลดอก (Float) เข้าข่ายการให้กู้ยืมหรือ P2P lending หรือไม่ และมีเพดานดอกเบี้ยตาม ป.พ.พ. ม.654 (15% ต่อปี) หรือไม่
- [ ] Microfinance (Phase 3) — ต้องมีใบอนุญาตประเภทใด (สินเชื่อรายย่อยระดับจังหวัด / P2P lending platform)

## 3. ก.ล.ต. / สินทรัพย์ดิจิทัล

- [ ] Contract **ไม่มีโทเคนและไม่ถือมูลค่า** → ไม่ใช่สินทรัพย์ดิจิทัล (ต้องยืนยัน)
- [ ] การใช้ public chain เป็นบันทึก — ต้องแจ้งผู้ใช้หรือไม่

## 4. PDPA

- [ ] ข้อมูลบน chain ห้ามเป็นข้อมูลส่วนบุคคล → บน chain มีเฉพาะ address, จำนวนเงิน, เวลา, hash
- [ ] address ผูกกับตัวบุคคลได้ผ่าน DB → ถือเป็นข้อมูลส่วนบุคคลแบบแฝงหรือไม่ แล้ว "สิทธิ์ในการลบ" ทำอย่างไรเมื่อข้อมูลบน chain ลบไม่ได้
- [ ] Consent สำหรับ KYC (บัตร, selfie = ข้อมูลชีวภาพ ม.26), เก็บรักษากี่ปี, DPO, การส่งข้อมูลไปผู้ให้บริการ KYC/LINE
- [ ] สลิปโอนเงินมีเลขบัญชีและชื่อ — เก็บใน storage ที่เข้ารหัสและกำหนดอายุการเก็บ

## 5. หลักฐานทางกฎหมาย

- [ ] Evidence Pack (PDF + tx hash + ลายเซ็นของผู้ใช้) ใช้เป็นพยานหลักฐานอิเล็กทรอนิกส์ตาม พ.ร.บ.ว่าด้วยธุรกรรมทางอิเล็กทรอนิกส์ได้หรือไม่ ต้องมีรูปแบบอย่างไร
- [ ] ข้อตกลงการเข้าวง (terms ของแต่ละวง) ควรให้สมาชิกลงนามอิเล็กทรอนิกส์ก่อน start

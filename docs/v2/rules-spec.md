## 1. หลักการ

- จำนวนเงินทั้งหมดเป็น **สตางค์** (จำนวนเต็ม)
- วงมีสมาชิก N คน = N รอบ = N ที่นั่ง และสมาชิกแต่ละคนได้รับเงินกองกลาง **ครั้งเดียว**
- ในแต่ละรอบ สมาชิกทุกคน **ยกเว้นผู้รับ** โอนเงินให้ผู้รับโดยตรงผ่าน PromptPay — ระบบไม่ถือเงิน
- "ยอด gross" ใน design (เช่น Receive 5,000) = ยอดที่ได้รับจริง + ส่วนของผู้รับเอง

## 2. ประเภทวง

### Fix — เลือกที่นั่ง (จาก Figma "Sit in")
- สมาชิกเลือกที่นั่งตอนเข้าวง ที่นั่ง k ได้รับเงินในรอบ k
- แต่ละที่นั่งจ่ายต่องวดคงที่ ไล่เป็นขั้นบันไดเชิงเส้นจาก `+fixRateBps` (ที่นั่งแรก) ถึง `−fixRateBps` (ที่นั่งสุดท้าย):

  `seatPayment(s) = principal + principal × fixRateBps × (N−1−2s) / ((N−1) × 10000)` (ปัดเศษเข้าหาศูนย์)

- ตัวอย่าง 5 ที่นั่ง เงินต้น 1,000 บาท ±10% → 1,100 / 1,050 / 1,000 / 950 / 900 บาท ผลรวมต่อรอบ = 5,000 = principal × N เสมอ
- คนที่ได้ก่อนจ่ายแพงกว่า (เหมือนจ่ายดอก) คนที่ได้ทีหลังจ่ายถูกกว่า (เหมือนได้ดอก)
- `fixRateBps = 0` คือวงแบบดั้งเดิมที่ทุกคนจ่ายเท่ากัน

### Float — ดอกตาม
- ทุกรอบที่มีการประมูล ผู้ที่ยังไม่เคยได้รับเงินยื่นซองเสนอ "ดอก" **ผู้เสนอสูงสุดชนะ** (เพดาน = `maxBid` ตาม [D3](./decisions.md#d3-เพดานดอกเบี้ยส่วนลด--15-ต่อปี-คิดแบบ-annualized-ปรับได้โดย-admin))
- ยอดจ่าย: คนที่ยังไม่เคยได้ → `principal` / คนที่ได้ไปแล้ว → `principal + ดอกที่ตนเคยประมูลชนะ`

### Discount — ดอกหัก
- ผู้ที่ยังไม่เคยได้รับเงินยื่นซองเสนอ "ส่วนลด" **ผู้เสนอสูงสุดชนะ** (เพดาน = `maxBid` และไม่เกิน principal − 1)
- ยอดจ่าย: คนที่ยังไม่เคยได้ → `principal − ส่วนลดของรอบนี้` / คนที่ได้ไปแล้ว → `principal`

## 3. รอบที่ไม่ต้องประมูล

| กรณี | ผู้รับ |
| --- | --- |
| วง Fix ทุกรอบ | เจ้าของที่นั่งตามลำดับ |
| Float/Discount รอบ 1 เมื่อ `hostTakesFirst` (มือนายวง) | นายวง (สมาชิกลำดับ 0) |
| รอบสุดท้าย | คนเดียวที่เหลือ |
| รอบที่ไม่มีใครเปิดซอง | สมาชิกที่มีสิทธิ์คนแรกตามลำดับการเข้าวง (ดอก 0) |

## 4. การประมูลแบบปิดซอง (commit–reveal)

1. **ยื่นซอง** (`bidWindow`): ส่งเฉพาะ `keccak256(circle, round, member, amount, salt)` ทำให้คนอื่นไม่เห็นราคาบน chain
2. **เปิดซอง** (`revealWindow`): ส่ง `amount` และ `salt` จริง ซองที่ไม่เปิดจะไม่ถูกนับ
3. **ตัดสิน**: ดอก/ส่วนลดสูงสุดชนะ ถ้าเท่ากันให้ **คะแนนความน่าเชื่อถือสูงกว่า** ชนะ ถ้ายังเท่ากันให้ **คนที่ยื่นซองก่อน** ชนะ

ผู้มีสิทธิ์ประมูล = ยังไม่เคยได้รับเงิน และไม่อยู่ในสถานะผิดนัด

ระบบ (worker) เก็บ `salt` ไว้ให้ผู้ใช้ และเปิดซองให้อัตโนมัติด้วยลายเซ็นของผู้ใช้ เพื่อไม่ให้ผู้ใช้ลืมเปิดซอง

## 5. การชำระและการผิดนัด

```
ผู้รับถูกเลือก ─ paymentWindow ─▶ deadline ─ grace ─▶ defaultAfter ─ grace ─▶ acceptAfter
                 (โอน + แจ้งโอน)              (แจ้งโอนได้ถึงตรงนี้)     (ผู้รับปฏิเสธได้ถึงตรงนี้)
```

| ขั้น | ใครทำ | เมื่อไร | ผล |
| --- | --- | --- | --- |
| `declarePayment(slipHash)` | ผู้จ่าย | ก่อน `defaultAfter` | แจ้งโอนพร้อม hash ของสลิป (สถานะ Declared) |
| `attestSlip` | signer (หลังตรวจสลิปกับธนาคารผ่าน) | ตอนสถานะ Declared | **นับว่าชำระแล้ว** ปฏิเสธหรือผิดนัดไม่ได้ |
| `confirmReceipt` | **ผู้รับ** | เมื่อไรก็ได้ | ชำระแล้ว (ใช้กับเงินสด และยืนยันการจ่ายล่าช้าหลังผิดนัดได้) |
| `rejectPayment` | ผู้รับ | ก่อน `acceptAfter` และยังไม่ Attested | เงินไม่เข้า → กลับเป็นยังไม่จ่าย ผู้จ่ายแจ้งใหม่ได้ถึง `defaultAfter` |
| `markDefault` | ใครก็ได้ (worker) | หลัง `defaultAfter` และ **ไม่เคยแจ้งโอน** | ผิดนัด: ประมูลไม่ได้ และถูกเลื่อนไปรับคนสุดท้าย |
| `acceptDeclared` | ใครก็ได้ (worker) | หลัง `acceptAfter` | แจ้งโอนที่ผู้รับไม่ตอบ ถือว่ารับแล้ว |

กติกานี้ทำให้ทั้งสองฝั่งโกงอีกฝั่งไม่ได้ง่ายๆ: ผู้รับที่เงียบจะทำให้ผู้จ่ายที่จ่ายจริงผิดนัดไม่ได้ ส่วนผู้จ่ายที่แจ้งโอนเท็จจะถูกผู้รับปฏิเสธได้
ถ้าไม่ตรงกัน (ผู้จ่ายยืนยันว่าโอนจริงแต่ผู้รับปฏิเสธ) ให้ใช้ `dispute` และสลิปเป็นหลักฐาน — `grace` ต้องอย่างน้อย 1 ชั่วโมง และ
`bidWindow + revealWindow + paymentWindow + 2×grace ≤ period`

รอบถัดไปจะเปิดได้เมื่อ (1) ทุกคนชำระแล้ว (Attested/Confirmed) หรือผิดนัด และ (2) ครบ `period` นับจากต้นรอบ

## 6. เพดานตามกฎหมาย (ตั้งค่าใน CircleFactory)

| เพดาน | ค่าเริ่มต้น |
| --- | --- |
| สมาชิกต่อวง | 30 |
| มูลค่าทุน (principal × N) | 300,000 บาท |
| วงที่เป็นนายวงพร้อมกัน | 3 |
| `fixRateBps` | ≤ 5,000 (±50%) และ `fixRateBps × 365 วัน ≤ maxAnnualRateBps × period` |
| `maxAnnualRateBps` (เพดานดอก/ส่วนลดต่อปี) | 1,500 (15%) |
| `trustedReputation` | 110 |
| `openTtl` (วงที่ไม่เริ่มยกเลิกได้โดยใครก็ได้) | 30 วัน |

ยอดที่ต้องโอนจริงอาจน้อยกว่าสูตรข้างบน เพราะหักกลบหนี้ผิดนัด ([D1](./decisions.md)) และรอบแรก ⌊N/2⌋ สงวนให้สมาชิกที่น่าเชื่อถือ ([D2](./decisions.md))

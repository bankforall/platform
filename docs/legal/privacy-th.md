# นโยบายความเป็นส่วนตัว {{APP_NAME}}

> **ร่าง — ต้องให้นักกฎหมายตรวจก่อนใช้งานจริง**

ฉบับวันที่ 4 ตุลาคม 2569 (เวอร์ชัน 2026-10-04)

นโยบายนี้อธิบายว่าเรา (ผู้ให้บริการ {{APP_NAME}}) เก็บ ใช้ เปิดเผย และลบข้อมูลส่วนบุคคลของคุณอย่างไร ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) และสิทธิของคุณในฐานะเจ้าของข้อมูล

## 1. ผู้ควบคุมข้อมูลส่วนบุคคล

- ผู้ควบคุมข้อมูล: [[ชื่อนิติบุคคลผู้ให้บริการ]] เลขทะเบียนนิติบุคคล [[เลขทะเบียน]]
- ที่อยู่: [[ที่อยู่สำนักงาน]]
- ติดต่อเรื่องข้อมูลส่วนบุคคล: อีเมล [[อีเมลติดต่อเรื่องข้อมูลส่วนบุคคล]]
- เจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO): [[ชื่อหรือตำแหน่ง DPO]] อีเมล [[อีเมล DPO]]

## 2. หลักการสำคัญ

- **ระบบไม่ถือเงินของคุณ** เงินโอนระหว่างสมาชิกโดยตรง เราจึงไม่เก็บเลขบัญชีธนาคารนอกจากที่ปรากฏบนสลิปที่คุณอัปโหลดเอง
- **ไม่มีข้อมูลส่วนบุคคลบนบล็อกเชน** บนเครือข่ายสาธารณะมีเพียงรหัสบัญชีแบบสุ่ม (address) จำนวนเงิน เวลา และค่า hash เท่านั้น
- ไฟล์บัตรประชาชน รูปถ่ายคู่บัตร และสลิป **ถูกเข้ารหัส (AES-256-GCM) ก่อนจัดเก็บ** ชื่อจริงตามบัตรถูกเข้ารหัส และ **เราไม่เก็บเลขประจำตัวประชาชนเต็ม**
- เราไม่ขายข้อมูล ไม่ใช้ข้อมูลเพื่อการตลาด ไม่ส่งโฆษณา และไม่ใช้เครื่องมือวิเคราะห์หรือติดตามพฤติกรรม (analytics/tracking)

## 3. ข้อมูลที่เราเก็บ

### 3.1 จากบัญชี LINE เมื่อเข้าสู่ระบบ

รหัสผู้ใช้ LINE (LINE user ID) ชื่อที่แสดง และลิงก์รูปโปรไฟล์ (เราไม่ได้รับอีเมลหรือเบอร์โทรจาก LINE) ชื่อและรูปจะอัปเดตทุกครั้งที่คุณเข้าสู่ระบบ

### 3.2 ที่คุณให้เราในแอป

- **เบอร์มือถือ** ยืนยันด้วยรหัส OTP ทาง SMS (เราเก็บรหัส OTP เป็นค่า hash และเวลาที่ขอ)
- **พร้อมเพย์สำหรับรับเงิน** (เบอร์มือถือหรือเลขประจำตัวประชาชน ถ้าคุณเลือกใช้เลขบัตรเป็นพร้อมเพย์ เลขนั้นจะถูกเก็บในฐานะพร้อมเพย์)
- **ข้อมูลยืนยันตัวตน (KYC)**: ชื่อ-นามสกุลตามบัตร (เข้ารหัส), รูปบัตรประชาชน, รูปถ่ายใบหน้าคู่บัตร (เข้ารหัส), เลขประจำตัวประชาชนซึ่ง **เก็บเฉพาะค่า HMAC** (ค่าที่คำนวณทางเดียวด้วยกุญแจลับ ใช้ตรวจว่าคนเดียวกันไม่เปิดหลายบัญชี ย้อนกลับเป็นเลขบัตรไม่ได้) และ **4 หลักท้าย**, ผลการตรวจและเหตุผลกรณีไม่ผ่าน
- **สลิปโอนเงิน** ที่คุณอัปโหลดเมื่อแจ้งโอน (เข้ารหัส) ซึ่งอาจมีชื่อและเลขบัญชีบางส่วนของคุณและผู้รับ พร้อมค่า hash ของไฟล์
- **ข้อความแจ้งปัญหา (dispute)** ที่คุณเขียน
- **ข้อมูลสำรองกุญแจ** ที่เข้ารหัสด้วยรหัสกู้คืนบนเครื่องของคุณ (เราถอดรหัสไม่ได้)
- จำนวนเงินที่คุณเสนอในการประมูลแบบปิดซอง (เข้ารหัส เพื่อเปิดซองให้อัตโนมัติตามเวลา)

### 3.3 ที่ระบบสร้างขึ้น

- รหัสบัญชีสำหรับลงนาม (wallet address) ที่สร้างบนเครื่องของคุณ
- การเป็นสมาชิกวง ที่นั่ง ผลการประมูล สถานะการชำระแต่ละงวด การผิดนัด และหนี้ค้าง (สำเนาจากบล็อกเชน)
- คะแนนความน่าเชื่อถือ (คำนวณจากประวัติการชำระบนบล็อกเชนและคะแนนเริ่มต้นที่เจ้าหน้าที่กำหนดตอนตรวจ KYC)
- การแจ้งเตือนที่ส่งถึงคุณ รายการธุรกรรมที่คุณลงนาม เวอร์ชันข้อกำหนดที่คุณยอมรับและเวลาที่ยอมรับ
- บันทึกการตรวจสอบ (audit log) ของการกระทำสำคัญ เช่น การตัดสิน KYC การเปิดดูไฟล์ KYC ของเจ้าหน้าที่ การเปลี่ยนกุญแจ การขอลบบัญชี
- ข้อมูลทางเทคนิค: IP address และข้อมูลคำขอใน log ของเซิร์ฟเวอร์ และตัวนับจำกัดความถี่ (rate limit) ชั่วคราว

### 3.4 ในเครื่องของคุณ

กุญแจลงนาม (เข้ารหัสด้วย PIN ใน IndexedDB ของเบราว์เซอร์) และคุกกี้ session ที่จำเป็นต่อการเข้าสู่ระบบ (httpOnly) เราไม่ใช้คุกกี้โฆษณาหรือคุกกี้วิเคราะห์

## 4. วัตถุประสงค์และฐานทางกฎหมาย

1. **ให้บริการตามสัญญา (ม.24(3))** — สร้างบัญชี เข้าสู่ระบบ ยืนยันเบอร์ จัดการวง คำนวณยอด สร้าง QR พร้อมเพย์ให้ผู้จ่าย ส่งต่อธุรกรรมที่คุณลงนาม แจ้งเตือนทาง LINE และในแอป ออกรายงานหลักฐานให้สมาชิกในวง
2. **ยืนยันตัวตนและป้องกันการฉ้อโกง (ประโยชน์โดยชอบด้วยกฎหมาย ม.24(5))** — ตรวจว่าหนึ่งคนมีหนึ่งบัญชี ป้องกันผู้ผิดนัดเปิดบัญชีใหม่ ยืนยัน OTP ก่อนเปลี่ยนพร้อมเพย์ ตรวจสอบย้อนหลังการกระทำของเจ้าหน้าที่ รักษาความปลอดภัยของระบบ
3. **ข้อมูลอ่อนไหว: รูปใบหน้า (ความยินยอมโดยชัดแจ้ง ม.26)** — ใช้เทียบกับรูปบนบัตรเพื่อยืนยันตัวตนเท่านั้น โดยเจ้าหน้าที่เป็นผู้ตรวจ [[ให้นักกฎหมายยืนยันว่ารูปถ่ายที่ตรวจด้วยคนถือเป็น "ข้อมูลชีวภาพ" ตาม ม.26 หรือไม่]] คุณให้ความยินยอมในขั้นตอน "ข้อตกลงการใช้งาน"
4. **การก่อตั้งสิทธิเรียกร้องและหลักฐาน (ม.24(5) และ ม.26(4))** — เก็บบันทึกการชำระ การผิดนัด และสลิป เพื่อเป็นหลักฐานให้สมาชิกในวงเดียวกันในกรณีมีข้อพิพาท แม้หลังจากคุณลบบัญชี (ดูข้อ 6)
5. **ปฏิบัติตามกฎหมาย (ม.24(6))** — ตรวจสอบเพดานตาม พ.ร.บ.การเล่นแชร์ พ.ศ. 2534 และตอบคำขอของหน่วยงานที่มีอำนาจตามกฎหมาย [[เพิ่มหน้าที่ตามกฎหมายอื่นถ้ามี]]

เราไม่มีการประมวลผลเพื่อการตลาด จึงไม่มีความยินยอมด้านการตลาดที่ต้องขอหรือถอน

## 5. ผู้ที่เห็นหรือได้รับข้อมูลของคุณ

- **สมาชิกในวงเดียวกัน** เห็นชื่อที่แสดง รูปโปรไฟล์ คะแนนความน่าเชื่อถือ รหัสบัญชีสำหรับลงนาม สถานะการชำระ และออกรายงานหลักฐานที่มีข้อมูลเหล่านี้ได้ **ผู้ที่ต้องโอนเงินให้คุณ** ได้ QR พร้อมเพย์ของคุณ (ในแอปแสดงแบบปิดบางส่วน) **ผู้รับเงินของงวด** เห็นสลิปที่จ่ายให้ตน วงสาธารณะแสดงชื่อนายวงให้ผู้ใช้คนอื่นเห็น
- **เจ้าหน้าที่ที่ได้รับอนุญาต** ตรวจ KYC (ทุกครั้งที่เปิดดูไฟล์จะถูกบันทึก) อนุมัติคำขอเปลี่ยนกุญแจ และดูแลระบบ
- **ผู้ให้บริการที่ประมวลผลข้อมูลแทนเรา (ผู้ประมวลผลข้อมูล)**:
  - LINE (LY Corporation) — เข้าสู่ระบบและส่งข้อความแจ้งเตือน (ส่ง LINE user ID และข้อความแจ้งเตือน)
  - ผู้ให้บริการ SMS [[ชื่อผู้ให้บริการ เช่น Twilio Inc. (สหรัฐอเมริกา)]] — ส่งรหัส OTP (ส่งเบอร์มือถือและข้อความ)
  - ผู้ให้บริการเซิร์ฟเวอร์และพื้นที่จัดเก็บไฟล์ (S3) [[ชื่อผู้ให้บริการและประเทศของ data center]] — เก็บฐานข้อมูลและไฟล์ที่เข้ารหัส
  - ผู้ให้บริการตรวจสลิปอัตโนมัติ [[ยังไม่ได้ใช้ — ถ้าเปิดใช้ ระบุชื่อ เพราะจะได้รับภาพสลิป]]
  - ผู้ให้บริการเชื่อมต่อเครือข่าย Base (RPC) [[ชื่อผู้ให้บริการ]] — ได้รับธุรกรรมที่ไม่มีข้อมูลส่วนบุคคล
  - Google Fonts — เบราว์เซอร์ของคุณโหลดแบบอักษรจาก Google ซึ่งจะเห็น IP address ของคุณ [[พิจารณาโฮสต์แบบอักษรเองเพื่อตัดการส่งข้อมูลนี้]]
- **เครือข่ายบล็อกเชน Base (สาธารณะ)** — ทุกคนในโลกเห็นได้และ **ลบหรือแก้ไขไม่ได้ตลอดไป** แต่มีเพียงรหัสบัญชีแบบสุ่ม จำนวนเงิน เวลา และค่า hash ไม่มีชื่อ เบอร์ เลขบัตร หรือภาพใดๆ ของคุณ อย่างไรก็ตามผู้ที่รู้ว่ารหัสบัญชีใดเป็นของคุณ (เช่น สมาชิกในวงเดียวกัน) จะเห็นประวัติการชำระของรหัสนั้นบนเครือข่ายได้
- **หน่วยงานรัฐ** เมื่อมีหน้าที่ตามกฎหมายหรือคำสั่งศาล

## 6. ระยะเวลาเก็บรักษา

- **ข้อมูลบัญชี** (ชื่อ LINE รูป LINE user ID เบอร์ พร้อมเพย์ ข้อมูลสำรองกุญแจ): ตลอดที่มีบัญชี ลบเมื่อการลบบัญชีเสร็จสิ้น
- **ข้อมูล KYC** (รูปบัตร รูปใบหน้า ชื่อจริง HMAC และ 4 หลักท้ายของเลขบัตร): ตลอดที่มีบัญชีเพื่อป้องกันการเปิดหลายบัญชี ลบเมื่อการลบบัญชีเสร็จสิ้น [[กำหนดระยะเวลาลบไฟล์ของ KYC ที่ไม่ผ่านการตรวจ — ปัจจุบันเก็บจนลบบัญชี]]
- **รหัส OTP และการแจ้งเตือน**: ลบเมื่อการลบบัญชีเสร็จสิ้น [[กำหนดระยะเวลาลบระหว่างที่ยังมีบัญชี]]
- **สลิปโอนเงิน**: ตลอดที่มีบัญชี หลังลบบัญชีเก็บต่อ **10 ปีนับจากวันที่วงจบ** (อายุความทั่วไปตาม ป.พ.พ. มาตรา 193/30) เพื่อเป็นหลักฐานให้สมาชิกคนอื่น แล้วลบไฟล์อัตโนมัติ (คงเหลือค่า hash ซึ่งอยู่บนบล็อกเชนอยู่แล้ว) [[ให้นักกฎหมายยืนยันระยะเวลา]]
- **บันทึกการเป็นสมาชิก การชำระ การผิดนัด หนี้ค้าง ธุรกรรม และข้อความแจ้งปัญหา**: เก็บต่อหลังลบบัญชีโดยผูกกับบัญชีที่ถูกทำให้ไม่ระบุตัวตน (ชื่อแสดงเป็น "ผู้ใช้ที่ลบบัญชีแล้ว") เพราะเป็นสำเนาของบันทึกบนบล็อกเชนที่สมาชิกคนอื่นใช้เป็นหลักฐานและใช้คำนวณยอดของวง [[ให้นักกฎหมายยืนยันระยะเวลา]]
- **บันทึกบนบล็อกเชน**: ถาวร ไม่มีผู้ใดลบได้
- **Audit log**: [[ระยะเวลา — ปัจจุบันเก็บไม่มีกำหนด]]
- **Log ของเซิร์ฟเวอร์**: หมุนเวียนตามขนาดไฟล์ (โดยประมาณไม่กี่วันถึงไม่กี่สัปดาห์) [[ระยะเวลาที่แน่นอนและ log ที่ส่งออกนอกเครื่อง]]
- **ข้อมูลสำรอง (backup) ที่เข้ารหัส**: [[ระยะเวลา]] ข้อมูลที่ลบแล้วจะหายจาก backup เมื่อ backup ชุดนั้นหมดอายุ

## 7. การส่งข้อมูลไปต่างประเทศ

ผู้ให้บริการบางรายประมวลผลข้อมูลนอกประเทศไทย เช่น LINE (ญี่ปุ่น/ไทย) ผู้ให้บริการ SMS [[ประเทศ]] Google Fonts (สหรัฐอเมริกา) และ data center [[ประเทศ เช่น สิงคโปร์]] เราส่งข้อมูลเท่าที่จำเป็นและ [[ระบุมาตรการคุ้มครองตาม ม.28/ม.29 เช่น สัญญามาตรฐาน หรือนโยบายคุ้มครองข้อมูลของผู้ให้บริการ]] เครือข่ายบล็อกเชนสาธารณะไม่มีประเทศที่ตั้งเฉพาะ แต่ไม่มีข้อมูลส่วนบุคคลถูกส่งขึ้นไป

## 8. สิทธิของคุณและวิธีใช้สิทธิ

คุณมีสิทธิต่อไปนี้ตาม PDPA โดยใช้ได้ในแอปที่หน้า **โปรไฟล์ → ข้อมูลส่วนบุคคลของฉัน** หรือติดต่อเราตามข้อ 1

1. **สิทธิเข้าถึงและขอรับสำเนา / สิทธิขอรับข้อมูลในรูปแบบที่อ่านด้วยเครื่องได้** — กด "ดาวน์โหลดข้อมูลของฉัน" เพื่อรับไฟล์ JSON ของข้อมูลทั้งหมดที่เราเก็บ (โปรไฟล์ เบอร์ พร้อมเพย์ สถานะและข้อมูล KYC ลิงก์ไฟล์ KYC และสลิป การเป็นสมาชิก การชำระ การแจ้งเตือน ธุรกรรม และ audit log ที่เกี่ยวกับคุณ) ทำได้ชั่วโมงละ 1 ครั้ง
2. **สิทธิแก้ไขข้อมูล** — แก้พร้อมเพย์ได้ในหน้าโปรไฟล์ ชื่อและรูปอัปเดตจาก LINE ทุกครั้งที่เข้าสู่ระบบ ข้อมูลอื่นติดต่อเรา
3. **สิทธิขอลบ (ลบบัญชี)** — กด "ขอลบบัญชี" ระบบจะลบหลังระยะรอ [[7 วัน]] ซึ่งคุณยกเลิกได้ **ระบบจะปฏิเสธคำขอระหว่างที่คุณยังอยู่ในวงที่ยังไม่จบหรือเปิดรับสมาชิกอยู่ หรือมีหนี้ผิดนัดค้าง** เพราะสมาชิกคนอื่นต้องใช้ข้อมูลของคุณในการรับ-ส่งเงินและติดตามหนี้ (ม.33 วรรคหนึ่ง ข้อยกเว้นเพื่อการก่อตั้งสิทธิเรียกร้องตามกฎหมาย) เมื่อลบแล้ว:
   - **ลบ**: รูปบัตร รูปใบหน้า ชื่อจริง HMAC และ 4 หลักท้ายของเลขบัตร เบอร์มือถือ LINE user ID ชื่อและรูปโปรไฟล์ พร้อมเพย์ ข้อมูลสำรองกุญแจ รหัส OTP และการแจ้งเตือน และเพิกถอนการเข้าสู่ระบบทุกเครื่อง
   - **เก็บต่อ**: รหัสบัญชีสำหรับลงนาม (address) และบันทึกการเป็นสมาชิก การชำระ การผิดนัด ธุรกรรม ข้อความแจ้งปัญหา และ audit log ผูกกับบัญชีที่ไม่ระบุตัวตน และสลิปตามระยะเวลาในข้อ 6 เพื่อเป็นหลักฐานให้สมาชิกคนอื่น
   - **ลบไม่ได้**: บันทึกบนบล็อกเชนสาธารณะ และรายงานหลักฐานที่สมาชิกคนอื่นดาวน์โหลดไปก่อนหน้า
   - หากเข้าสู่ระบบด้วย LINE เดิมหลังลบบัญชี จะได้บัญชีใหม่ที่ไม่มีประวัติเดิม
4. **สิทธิถอนความยินยอม** — คุณถอนความยินยอมในการใช้รูปใบหน้าได้โดยขอลบบัญชี (เราใช้รูปใบหน้าเพื่อยืนยันตัวตนเท่านั้น หากถอนความยินยอมจะใช้งานวงแชร์ต่อไม่ได้) การถอนความยินยอมไม่กระทบการประมวลผลที่ทำไปแล้ว
5. **สิทธิคัดค้าน และสิทธิขอให้ระงับการใช้ข้อมูล** — ติดต่อเราตามข้อ 1
6. **สิทธิร้องเรียน** — ต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส.) www.pdpc.or.th

เราจะตอบคำขอที่ส่งถึงเราภายใน 30 วัน และอาจขอให้ยืนยันตัวตนก่อนดำเนินการ

## 9. ความปลอดภัย

ไฟล์และข้อมูลสำคัญเข้ารหัสก่อนจัดเก็บ การเชื่อมต่อใช้ HTTPS กุญแจลงนามอยู่บนเครื่องของคุณเท่านั้น การเปลี่ยนกุญแจต้องมีเจ้าหน้าที่ 2 คนอนุมัติ การเข้าถึงไฟล์ KYC ของเจ้าหน้าที่ถูกบันทึกทุกครั้ง ซอร์สโค้ดเปิดเผยให้ตรวจสอบได้ หากเกิดเหตุละเมิดข้อมูลส่วนบุคคล เราจะแจ้ง สคส. ภายใน 72 ชั่วโมงและแจ้งคุณตามที่กฎหมายกำหนด

## 10. การเปลี่ยนแปลงนโยบาย

เมื่อมีการเปลี่ยนแปลงสาระสำคัญ แอปจะแสดงฉบับใหม่และขอให้คุณยอมรับอีกครั้งก่อนใช้งานต่อ ฉบับปัจจุบันดูได้ที่หน้า "นโยบายความเป็นส่วนตัว" ในแอปเสมอ

## สิ่งที่ต้องเติม (placeholder)

| รูปแบบ | ความหมาย | ตัวอย่าง |
| --- | --- | --- |
| `[[...]]` | ข้อมูลที่บริษัท/นักกฎหมายต้องกรอกหรือตัดสินใจ แอปแสดงเป็นแถบสีเหลืองเพื่อให้เห็นว่ายังไม่ครบ | `[[ชื่อนิติบุคคลผู้ให้บริการ]]`, `[[ที่อยู่สำนักงาน]]`, `[[อีเมล DPO]]` |
| `{{APP_NAME}}` | ชื่อบริการ แทนที่อัตโนมัติด้วย `VITE_APP_NAME` ตอน build (ค่าเริ่มต้น "Bank For All") — ชื่อที่มีคำว่า "Bank" อาจใช้ไม่ได้ตามกฎหมายไทย รอความเห็นนักกฎหมาย | |

รายการ placeholder ที่ต้องกรอกก่อนเปิดใช้งาน:

- ตัวตนผู้ควบคุมข้อมูล: ชื่อนิติบุคคล, เลขทะเบียนนิติบุคคล, ที่อยู่, ช่องทางติดต่อ
- เจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO): ชื่อหรือตำแหน่ง, อีเมล, ที่อยู่ (ม.41 — ต้องตั้งหรือไม่ขึ้นกับขนาดการประมวลผลข้อมูลอ่อนไหว ให้นักกฎหมายยืนยัน)
- ผู้ให้บริการจริงและประเทศที่ตั้ง: VPS/data center, object storage, SMS, RPC ของ Base, ผู้ให้บริการตรวจสลิป (ถ้ามี)
- ระยะเวลาเก็บที่ยังไม่ได้กำหนด: audit log, backup, log ของเซิร์ฟเวอร์, KYC ที่ไม่ผ่านการตรวจ
- อายุขั้นต่ำของผู้ใช้, ค่าบริการ (ถ้ามี), เขตอำนาจศาล

## เมื่อแก้ไขเอกสาร

1. แก้ไฟล์ `.md` ในโฟลเดอร์นี้
2. ถ้าเป็นการเปลี่ยนแปลงสาระสำคัญ ให้เปลี่ยน `TERMS_VERSION` ใน `packages/shared/src/api.ts` และวันที่ "ฉบับวันที่" ในทั้งสองไฟล์ให้ตรงกัน
   ผู้ใช้ทุกคนที่ยอมรับฉบับเก่าจะถูกพาไปขั้นตอน "ข้อตกลงการใช้งาน" อีกครั้งและต้องกดยอมรับก่อนใช้งานต่อ
   (เวอร์ชันที่ยอมรับและเวลาเก็บใน `User.consentVersion` / `User.consentAt`)
3. build และ deploy web + api ใหม่พร้อมกัน (API ปฏิเสธ consent ที่ไม่ใช่ `TERMS_VERSION` ปัจจุบัน)

## ข้อกำหนดของระบบที่เอกสารอ้างถึง

| เรื่องในเอกสาร | ที่มาในระบบ |
| --- | --- |
| ส่งออกข้อมูลของฉัน | `GET /api/me/export` (จำกัด 1 ครั้งต่อชั่วโมง) — หน้าโปรไฟล์ → "ข้อมูลส่วนบุคคลของฉัน" |
| ลบบัญชี | `POST/DELETE /api/me/deletion-request`, worker `executeDueDeletions` (`apps/api/src/services/privacy.ts`) |
| ระยะเวลารอก่อนลบ | `ACCOUNT_DELETION_DELAY_DAYS` (ค่าเริ่ม 7 วัน) |
| อายุการเก็บสลิปหลังลบบัญชี | `DELETED_SLIP_RETENTION_DAYS` (ค่าเริ่ม 3650 วัน ≈ 10 ปี นับจากวงจบ) |
| ความยินยอม | `TERMS_VERSION`, `POST /api/me/consent` |

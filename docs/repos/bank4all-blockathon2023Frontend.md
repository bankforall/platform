## 1. โครงสร้าง

```
bank4all-blockathon2023Frontend/
├── public/index.html          # template จาก Anima
├── src/
│   ├── main.js                # new Vue({ router }) + import styleguide.css, globals.css
│   ├── App.vue                # <router-view />
│   ├── router.js              # mode: history, 19 routes
│   ├── data.js                # props/ข้อความของทุกหน้า (926 บรรทัด)
│   └── components/*.vue       # 30 components (ชื่อแปลกๆ เช่น DashboarD, LogiN, xMaiN — ดูข้อ 4)
├── img/                       # SVG/PNG ที่ export จาก Figma (รูปส่วนใหญ่ใน data.js ยังชี้ไป S3 ของ Anima)
├── styleguide.css, globals.css
├── src.rar                    # สำเนา src/ รุ่นเก่า (2023-05-02) ในรูป RAR
├── lintCorrecter.js           # สคริปต์ rename component ให้ผ่าน ESLint
├── routerUpdate.js            # สคริปต์แก้ชื่อ import ใน router.js
└── package.json               # name: "hello-world"
```

## 2. การรัน

```bash
npm install
npm install vue-router@3      # ⚠️ router.js import "vue-router" แต่ไม่ได้อยู่ใน package.json
npm run serve                 # vue-cli-service serve → http://localhost:8080
```

> README ที่ Anima generate ให้ใช้ `cd package_code && npm start` ซึ่งไม่ตรงกับโครงสร้าง repo — ให้ใช้ `npm run serve`

## 4. หมายเหตุเกี่ยวกับชื่อ component แปลกๆ

ESLint (`vue/multi-word-component-names`) ไม่ยอมให้ component ชื่อคำเดียว ผู้พัฒนาจึงเขียน `lintCorrecter.js`
และ `routerUpdate.js` เพื่อ rename อัตโนมัติ (เช่น `Frame12 → FramE12`, `Group41 → GrouP41`, `Submit → SubmiT`)
แทนที่จะปิด rule — ในคอมเมนต์ยอมรับว่าบางส่วน "not working"

## 5. ข้อควรรู้

- ไม่มี state management, ไม่มีการเชื่อมกับ `bank4all-smartcontract` (API port 1234)
- ปฏิทินในหน้า Create room เป็นตัวเลขคงที่ (December 2022)
- ถ้าจะใช้ต่อ แนะนำให้เขียนใหม่ (Vue 3 / React) โดยใช้ repo นี้เป็น reference ด้าน UX/ข้อความ
